# 串口协议

物理格式：8N1、无流控。主模式标称3,000,000 baud；传统单帧模式115200。字节流在 ASCII 遥测行与完整二进制图像包之间复用，禁止按像素内容搜索换行、字段或包头。

## PC → FPGA

单字节 ASCII 命令，无换行、无应答包：

| 字节 | 行为 |
|---|---|
| `P` / 0x50 | 请求160×90连续预览 |
| `Q` / 0x51 | 请求320×180连续预览 |
| `H` / 0x48 | 请求一次1280×720 RGB888抓图，完成后暂停图像 |

正在发送的图像不会被命令截断。控制逻辑保存目标模式/单次请求，尚未开始的请求可被后来的命令替换；它不是无限队列。

## FPGA → PC 图像

所有多字节整数均小端。包头10字节，CRC尾2字节。

| 偏移 | 长度 | 字段 |
|---|---|---|
| 0 | 4 | ASCII `HXP1`（RGB565预览）或 `HXF2`（RGB888单帧） |
| 4 | 2 | 宽度 |
| 6 | 2 | 高度 |
| 8 | 2 | HXP1固定为2；HXF2为每行128bit字数 `ceil(width*3/16)` |
| 10 | 可变 | 像素载荷 |
| 末尾 | 2 | CRC16，小端 |

HXP1 每像素16位小端，位[15:11]=R5、[10:5]=G6、[4:0]=B5，行优先，载荷为 W×H×2。支持预览尺寸不超过320×180。

HXF2 每像素按 R、G、B 三字节，行优先；每行补齐到16字节，载荷长度为 strideWords×16×H。DDR发送按每个128bit字从最高字节到最低字节输出。当前1280×720每行3840字节，无行尾填充。

CRC参数：CRC16-CCITT-FALSE，poly=0x1021、init=0xFFFF、refin=false、refout=false、xorout=0。覆盖完整10字节包头与所有载荷（含行尾填充），不包含CRC尾本身。标准测试字符串 `123456789` 的结果为0x29B1。

包示例：160×90载荷28800字节；320×180载荷115200字节；1280×720 RGB888载荷2764800字节。每包总长为载荷+12。

## FPGA → PC 遥测

旧格式54字节，以CR/LF结尾：

```text
XC:0632.41 YC:0359.82 DX:-008.19 DY:+000.10 N:001234\r\n
```

扩展格式73字节：

```text
XC:0632.41 YC:0359.82 DX:-008.19 DY:+000.10 N:001234 M:3 A:1 G:150 V:18\r\n
```

示例中的 `\r\n` 表示两个实际控制字节。XC/YC/DX/DY为px，ASCII固定两位小数；RTL输入为20位Q12.8（偏差为有符号），坐标数据由外部算法提供。N=0时接收端显示LOST。接收器兼容旧5位N和当前6位N。

M：0原图/1增强/2边缘/3结果，仅为外部模式编号；A：AGC开关；G：`100 + floor(I_gain_ex*100/128)`，为数字增益百分比；V：协议能力标记18，不是本仓库软件发布号。

遥测和图像没有共同帧号、采集时间戳或独立元数据包，不能据此推断严格同帧。图像期间暂停遥测，不代表坐标算法停止运行。
