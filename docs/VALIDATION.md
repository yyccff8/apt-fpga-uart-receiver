# 测试与验证边界

## 可复现命令

Windows接收端：

```powershell
powershell -ExecutionPolicy Bypass -File .\receiver\src\Build.ps1
powershell -ExecutionPolicy Bypass -File .\receiver\src\Test.ps1
```

固件传输：PATH需有Icarus Verilog（iverilog/vvp）和Python3，仅用于仿真：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Run-FirmwareTests.ps1
```

测试输出在各自build目录，不纳入Git。测试程序不打开可见窗口，不连接板子；界面采用离屏绘制检查布局与叠加层。

## 覆盖范围

| 项目 | 证据与边界 |
|---|---|
| 旧协议与RGB565接收 | 3959项断言，含分块输入、CRC、旧帧/预览混合流、像素解码与RTL样本 |
| 新档位/元数据/叠加 | 552项检查，含RGB888/RGB565样本、扩展与旧遥测、叠加不修改原图、离屏布局 |
| 独立传输封装 | apt_transport编译、实际串口位输入P/Q/H，忙时等待、图像保留、恢复预览；其它忙信号由测试平台提供 |
| DDR发送小帧 | profile0/1/2，跨128bit字边界、ready等待及单个未决读请求 |
| 完整320×180 | 1280×720模型的57600个中心采样像素、完整地址范围和CRC逐个验证；UART分频加速以缩短地址测试时间 |
| 名义3M接收采样 | DDR发送实际整数分频22，用名义3M采样读取小帧，结果与质量档包相同 |
| 遥测格式 | 54字节旧行、73字节扩展行，精确比较字节 |

## 已知限制与未验证事项

- 原完整工程的160×90预览由用户上板确认，截图显示约8.5 fps；本仓库抽取后的封装没有独立上板验证，该数值不是本版测速。
- 320×180预计约1–2 fps、720p抓图约9秒以上来自带宽与处理路径估算，真实结果待测。
- 未提供目标工程完整时钟约束、CDC签核或全系统路由报告；原完整工程的Setup/Hold余量不能移用为独立封装的签核结果。
- DDR控制器/FIFO时延变化、其它仲裁器、不同板卡/时钟、源槽位冻结和显示并发必须在实际工程验证。
- UART有约1%分频偏差；尚无拆分版长时间CRC、USB插拔、错误恢复及命令闭环的实板统计。
- 像素采样没有低通滤波，细线可能混叠；320×180仍非720p原图。3M串口不支持720p60。
- 遥测没有与图像共享帧号，显示的坐标不能直接作为严格同帧测量。
- 所有图像样本是合成/RTL仿真数据；没有上传实拍、个人日志或设备端口记录。

维护者应在修改协议、时钟、分辨率、DDR握手或缓存所有权逻辑后更新相关测试和本文件。
